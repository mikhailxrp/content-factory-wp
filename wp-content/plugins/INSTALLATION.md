# Установка плагина Content Factory UI

## Способ 1: Через админку WordPress (рекомендуется)

1. Скачайте файл `content-factory-ui.zip`
2. Войдите в админку WordPress
3. Перейдите в **Плагины → Добавить новый**
4. Нажмите **Загрузить плагин** (вверху страницы)
5. Выберите файл `content-factory-ui.zip`
6. Нажмите **Установить**
7. После установки нажмите **Активировать**

## Способ 2: Через FTP/SSH

1. Распакуйте архив `content-factory-ui.zip`
2. Загрузите папку `content-factory-ui` в `wp-content/plugins/`
3. Войдите в админку WordPress
4. Перейдите в **Плагины**
5. Найдите **Content Factory UI** и нажмите **Активировать**

## Настройка после установки

1. В админке WordPress перейдите в **Content Factory → Настройки**
2. Укажите **URL вашего n8n сервера** (например: `https://n8n.example.com`)
3. Настройте endpoints для каждого раздела:
   - Смыслы
   - Темы
   - Статьи
   - Telegram
   - Промпты
4. Нажмите **Сохранить настройки**
5. Проверьте соединение с n8n через кнопку **Тест соединения**

## Требования

- WordPress 5.8+
- PHP 7.4+
- Настроенный n8n сервер с webhook endpoints

## Что входит в плагин

- Управление контекстом (ниша, целевая аудитория)
- Генерация смыслов из контекста
- Создание и редактирование тем
- Генерация статей и создание черновиков в WordPress
- Генерация статей прямо из редактора Gutenberg
- Публикация постов в Telegram
- Управление промптами для генерации
- Логирование всех операций

## Удаление

При удалении плагина через WordPress автоматически удаляются:

- Все настройки плагина
- Транзиенты кэша
- Мета-данные постов, связанные с плагином

Это гарантирует чистое удаление без остаточных данных в БД.
